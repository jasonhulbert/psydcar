Remove sidecar

This deletes the sidecar and its search index. MCP connections that include it will stop starting. The folder and its files are not touched.

Embedding provider

Any OpenAI-compatible embeddings endpoint works, including gateways and local model servers. Once saved, updates send indexed passages to this endpoint and searches send the query.

Test sends only the phrase “Psydcar provider connection test”, never your files.

Remove embedding provider

This removes the provider settings and all stored vectors. Keyword search and your sidecars stay available, and you can add a provider again later.
